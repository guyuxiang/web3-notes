# 二、存款代币 vs 稳定币（核心区别）

文章提到一个关键概念：

> 存款代币可以产生利息

这是 **传统金融体系的关键优势**。

| 维度   | 稳定币        | 存款代币     |
| ------ | ------------- | ------------ |
| 发行方 | 稳定币公司    | 商业银行     |
| 资产   | 国债 / 现金   | 银行存款     |
| 利息   | 发行方赚      | 用户赚       |
| 监管   | 支付/电子货币 | 银行监管     |
| 风险   | 储备透明度    | 银行信用风险 |
| 典型   | USDT / USDC   | JPM Coin     |

总结一句话：

**稳定币 = 货币市场基金 Token**

**存款代币 = 银行存款 Token**

| 工作时间限制 | 银行营业时间 |

```

```
3秒

这就是 JPM Coin 的核心价值：

**银行级 RTGS（实时结算系统）**

```

```

```

```

```

```

```

```

```
资产

银行通常会把资金配置到：

```

例如收益：

```
5%
```

```
50万美元
```

Token 的利息就是从这里来。



# 代币化存款的三种收益实现方式

在架构上主要有 **3种设计**。

------

# 1 Rebase Token（自动增加余额）

类似：

- stETH
- aToken (Aave)

Token 数量会自动增长。

例子：

```
初始

Alice
100 JPMD
```

利息 5%

一年后：

```
Alice
105 JPMD
```

Token supply 变成：

```
100 → 105
```

智能合约逻辑：

```
balance = principal * interestIndex
```

优点

- 用户体验好
- 自动复利

缺点

- 会影响 DeFi 兼容性

------

# 2 Exchange Rate 模型（最常见）

类似：

- Compound cToken
- ERC4626 Vault

Token 数量不变，但 **价值上涨**。

例如：

```
初始

1 JPMD = $1
```

一年后：

```
1 JPMD = $1.05
```

Alice：

```
100 JPMD
```

赎回：

```
100 × 1.05 = $105
```

智能合约：

```
price = totalAssets / totalSupply
```

优点：

- DeFi兼容性最好
- 不改变 token balance

这也是 **银行最可能采用的模型**。

------

# 3 分红模型（Dividend）

类似：

- staking reward

定期发放收益。

例如：

```
100 JPMD
```

银行每月发：

```
0.4 JPMD
```

合约逻辑：

```
rewardPerToken
```

优点

- 简单

缺点

- 体验差

------

# 三、银行如何把利息同步到链上

银行核心系统会计算利息。

流程一般是：

```
银行核心系统
      │

API
      │
Oracle
      │
更新链上利率
```

例如：

```

```

然后更新合约：

```
updateExchangeRate()
```
