## 中继层

将不同区块链的交互和密钥管理进行抽象制作成钱包供用户和前端应用使用，可以基于kms服务，实现多链密钥管理、交易签名和gas中继服务，在中继层完成多链抽象

1. 统一地址：生成多链地址，从单个助记词派生多个链的私钥和地址，另外提供邮箱等建立无私钥账户的方式，账户支持恢复
2. 签名抽象：一个账户可以签署多链交易，封装不同链的sdk，根据用户指定的链进行签名
3. Gas中继：用户不需要持有Gas Token进行交易，针对不同链采用专门的中继器帮助用户完成交易，如EVM链使用ERC-4337账户抽象、Aptos链使用[AIP-39](https://github.com/aptos-foundation/AIPs/blob/main/aips/aip-39.md)赞助交易，XRPL链使用自动化TopUp方式，根据用户交易需求自动为用户转账Gas Token
4. 统一Gas: gas中继服务费使用平台原生稳定币作为多链通用gas代付token，实现稳定币和gas token的兑换
5. 跨链：使用A链的资金，购买B链的资产，使用领域特定语言 (DSL) 规范确定不同链合约调用交易意图的输入，中继器完成相应的跨链操作，并自动完成两条链的交易签名



### 统一地址

| 区块链 |   算法    | 原始私钥长度 |                   编码格式                    |
| :----: | :-------: | :----------: | :-------------------------------------------: |
| 比特币 | secp256k1 |    32字节    |           Base58Check（添加校验和）           |
| 以太坊 | secp256k1 |    32字节    | Hex（32字节私钥转换为64字符的十六进制字符串） |
|  XRP   | secp256k1 |    32字节    |                  Base58Check                  |
| Aptos  |  Ed25519  |  32字节种子  |            扩展为64字节密钥对后Hex            |
| Solana |  Ed25519  |  32字节种子  |                    Base58                     |

1.通过 BIP-39 标准将助记词转换为种子（Seed）

2.使用 BIP-44 派生路径，生成的私钥的原始字节

​	BIP-44 定义了层级结构：
​	`m / purpose' / coin_type' / account' / change / address_index`
​	其中不同链的 `coin_type` 不同（如 ETH 为 `60`，Aptos 为 `637`），（完整列表见 SLIP-44）

​	https://github.com/satoshilabs/slips/blob/master/slip-0044.md
