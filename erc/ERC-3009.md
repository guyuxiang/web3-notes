# ERC-3009

**用签名直接完成 token 转账（gasless transfer）**

**EIP-3009** 是一个以太坊代币扩展标准，全名是：

> **Transfer With Authorization**

它允许用户**用签名授权转账，而不需要自己发送链上交易**，从而实现所谓的 **Gasless Transfer（免 Gas 转账）**。

第三方（Relayer）帮他提交交易并支付 Gas

**它引入两个函数：**

```
function transferWithAuthorization(
    address from,
    address to,
    uint256 value,
    uint256 validAfter,
    uint256 validBefore,
    bytes32 nonce,
    uint8 v,
    bytes32 r,
    bytes32 s
) external;
```

核心逻辑：

1. 用户对一段数据进行 **EIP-712 签名**
2. 签名包含：
   - from
   - to
   - value
   - validAfter
   - validBefore
   - nonce
3. 任何人都可以拿着这个签名提交链上交易
4. 合约验证签名正确后执行转账

```
User 签名  →  Relayer 提交交易  →  合约验证签名  →  执行转账
(不花Gas)       (花Gas)             (EIP-712)         (完成转账)

```

##### **时间窗口**

```
validAfter <= now <= validBefore
```

防止：

- 永久有效签名

##### nonce 必须唯一

```
mapping(bytes32 => bool) used;
```



##  receiveWithAuthorization

```
function receiveWithAuthorization(...)
```

👉 防止“抢跑（front-running）”

👉 只有 `to` 地址可以调用



## cancelAuthorization

```
function cancelAuthorization(...)
```

👉 撤销一个未使用的签名



# 为什么用 bytes32 nonce？

ERC-3009 的一个设计亮点：

```
bytes32 nonce;
```

而不是递增 nonce。

并且链上通常是这样存的：

```
mapping(address => mapping(bytes32 => bool)) public authorizationState;
```

👉 含义：

- `false` → 未使用
- `true` → 已使用 / 已取消

特点：

- 任意值（通常随机）
- 无顺序要求
- 支持并发签名
