# MakerDao

2023 年 6 月，MakerDAO 将美国国债整合到其投资组合中，这一举措意味着其正在通过利用 RWA 来使其收入来源多元化



**MakerDAO** 和 **Spark Protocol** 的关系

MakerDAO：

- **铸造 DAI / USDS**
- 将其 **直接存入 Spark**

Spark：

- 将这部分 DAI 借给市场用户
- 收取利息

**产品定位关系：Maker 发币，Spark 放贷**

### MakerDAO 负责什么？

- 抵押品管理（ETH、RWA、stETH 等）
- 稳定币发行（DAI → USDS）
- 利率锚定（DSR、稳定费）
- 系统风险控制

### Spark 负责什么？

- 类 Aave 的借贷体验
- DAI / USDS 的**真实使用场景**
- DeFi 市场中的：
  - 杠杆
  - 套利
  - 利率传导

| 项目     | 核心角色                |
| -------- | ----------------------- |
| MakerDAO | **央行 + 资产负债表**   |
| Spark    | **商业银行 + 借贷市场** |

Spark **技术上 fork 自 Aave v3**

 **Spark 是 Maker 从“稳定币项目”进化为“DeFi 银行体系”的关键一步**
