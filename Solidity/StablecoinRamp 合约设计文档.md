## 一、系统概述

#### **概念介绍：**

**On-ramp**

指 **从法币世界进入加密世界** 的通道或流程。

用户使用法币（如 USD、CNY、EUR）购买加密资产（如 BTC、ETH、USDT、USDC）的过程。

可以理解为“**入金**”或“**充值**”。

**Off-ramp**

指 **从加密世界回到法币世界** 的通道或流程。

用户将加密资产卖出换成法币（提现、出金）的过程。

可以理解为“**出金**”或“**提现**”。



`StablecoinRamp` 合约（原名 `Encash`）用于在链上实现 **稳定币入金（On-ramp）** 与 **出金（Off-ramp）** 的流程。
 它是整个 **RWA 稳定币支付与结算体系** 的资金流核心组件，
 用于连接 **用户端钱包、发行方合约、KYC 权限系统** 和 **外部法币清结算系统**。

合约提供完整的生命周期管理：

- On-ramp（入金）（用户购买或充值稳定币）

- Off-ramp（出金）（用户赎回或提现稳定币）

- 发行方批准 / 驳回请求

- 合规校验（通过 `UserPermission` 与 `Config` 模块）

- 状态追踪与事件通知

  

## 二、设计目标

| 目标         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **合规性**   | 所有操作均受 `UserPermission` 模块限制，确保仅合格账户参与。 |
| **易用性性** | 资金转移均可以通过签名授权（`Permit2`）提高易用性            |
| **可升级性** | 采用 `UUPSUpgradeable` 模式，支持未来版本升级。              |
| **安全性**   | 生成唯一业务流水号防重放，所有请求均有唯一业务 ID（`TransactionIDFactory` 生成），状态变更全链上记录。且支持暂停（`pause/unpause`）。 |
| **扩展性**   | 支持多代币，支持自发性代币和第三方稳定币，提供注册代币的功能 |

## 三、核心功能

### 3.1 On-ramp （入金）

用户使用法币购买稳定币，对应链上行为为 “购买” 或 “充值” 稳定币代币。

#### 主流程函数

| 函数              | 说明                                                 |
| ----------------- | ---------------------------------------------------- |
| `requestOnRamp()` | 用户发起入金请求（链上记录交易信息）                 |
| `approveOnRamp()` | 发行方确认入金向用户转账稳定币                       |
| `rejectOnRamp()`  | 入金被拒绝（例如合规或风控不通过）                   |
| `instantOnRamp()` | 发行方直接完成入金并批准（快捷入金）向用户转账稳定币 |

### 3.2 Off-ramp（出金）

用户赎回稳定币（提取法币），合约通过 **销毁代币（burn）** 或 **转账冻结账户** 来实现链上出金流程。

#### 主流程函数

| 函数               | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| `requestOffRamp()` | 用户发起出金请求（转入合约）                                 |
| `approveOffRamp()` | 发行方批准出金，自发行稳定币进行burn操作，第三方稳定币继续存在合约中供管理员后续提取 |
| `rejectOffRamp()`  | 发行方拒绝出金请求并退回或转入待处理账户                     |

#### On/Off-ramp状态管理

| 状态码              | 含义               | 应用场景       |
| ------------------- | ------------------ | -------------- |
| `REQUEST_INITIATED` | 请求已创建，待处理 | 用户刚提交     |
| `REQUEST_APPROVED`  | 请求已批准         | 发行方确认完成 |
| `REQUEST_REJECTED`  | 请求被拒绝         | 拒绝或异常     |



### 3.3 管理

管理员管理合约资金池

#### 主流程函数

| 函数                                                       | 说明                          |
| ---------------------------------------------------------- | ----------------------------- |
| `RegistryToken(address token)`                             | 注册可用于On/Off-ramp的稳定币 |
| `depositsToken(address token, address to, uint256 amount)` | 向合约中存入指定金额的稳定币  |
| `withdrawToken(address token, address to, uint256 amount)` | 提取合约中指定金额的稳定币    |
| `pause() / unpause()`                                      | 暂停或恢复系统                |
