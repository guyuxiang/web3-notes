## 合约紧急暂停功能

每个业务合约继承openzeppelin Pausable合约

合约函数增加修饰器, 该修饰器会判断目前的暂停标志,检查合约当前必须处于非暂停状态，否则revert

```solidity
modifier whenNotPaused()
modifier whenPaused()
```



在合约暂停函数中使用修饰器, 对权限控制, 只有指定权限用户或者治理合约才能进行调用

```solidity
function paused() public view virtual returns (bool)
function _pause() internal virtual whenNotPaused
function _unpause() internal virtual whenPaused
```



管理员账户或者合约来调用各个合约的暂停函数, config合约需要存储每个业务合约的地址,用治理合约查询来调用暂停
